About this page

This policy explains how information is handled by the YouTube channel "仮想通貨ラジオ" (Kasotuka Radio) and the tools used to operate it.

1. 動画投稿用の道具（YouTube API の利用）

運営者は、自分のパソコンで動く自作の道具を使い、YouTube API サービスで自分のチャンネルに動画を投稿しています。

  • 使うのは、運営者本人の YouTube チャンネルだけです。ほかの人のアカウントやデータには触れません。
  • 使う機能は、動画のアップロード、サムネイルの設定、自分のチャンネルの確認だけです。
  • 視聴者やほかの利用者の情報は、集めない・保存しない・表示しない・第三者に渡しません。
  • 保存するのは、投稿した動画の ID だけです。運営者のパソコンの中に記録します。
  • ログインの情報（認証用のトークン）は運営者のパソコンの中だけに置き、外には出しません。

この道具は YouTube API サービスを使っています。YouTube 利用規約と Google プライバシーポリシーもご確認ください。アクセスの許可は、Google アカウントの設定からいつでも取り消せます。

Video upload tool (use of YouTube API Services)

The operator uses a private, self-made tool running on their own PC to upload videos to their own channel through the YouTube API Services.

  • It accesses only the operator's own YouTube channel. No other users' accounts or data are accessed.
  • It only uploads videos, sets thumbnails, and confirms the authenticated channel.
  • It does not collect, store, display, or share any data of viewers or other users.
  • The only thing stored is the ID of each uploaded video, kept locally on the operator's PC.
  • OAuth tokens are stored only on the operator's PC and are never shared.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time from the Google security settings page.

2. 税金シミュレーター

無料プレゼントの「仮想通貨の税金シミュレーター」（https://kasotuka-radio.github.io/tax/）に入れた数字は、お使いのスマホやパソコンの中だけで計算します。どこにも送りません。

「今の値段を入れる」ボタンを押したときだけ、値段を調べるために CoinGecko（外部のサービス）に問い合わせます。このとき、入力した金額などは送りません。

Tax simulator

Numbers entered into the free tax simulator are calculated only on your device and are never sent anywhere. Only when you press the "current price" button, the page requests the latest price from CoinGecko, an external service; your inputs are not sent.

3. メールアドレスの登録

シミュレーターを受け取るために登録していただくメールアドレスは、配信サービス（ステップメールの配信サービス）で管理します。使うのは、シミュレーターのお届けと、仮想通貨に関するお知らせを送るためだけです。第三者に売ったり渡したりはしません。届くメールの中のリンクから、いつでも配信を止められます。

Email registration

Email addresses registered to receive the simulator are managed by an email delivery service. They are used only to deliver the simulator and send crypto-related updates, and are never sold or shared with third parties. You can unsubscribe at any time from the link in each email.
